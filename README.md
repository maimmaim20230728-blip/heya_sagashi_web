# わたしに合う部屋さがし・そよぎ (Web版)

賃貸の部屋さがしで、探す前から住んだあとまでにすることを、やさしい言葉のカードと内見のチェックシートで。頼んでよいことと使える仕組みも。端末内のみ・オフライン・登録なし。

- 版: 0.1.0(Play版と同じ中身)
- 無料・広告なし・登録なし。書いたことはこの端末の中だけに保存され、どこにも送られません
- 日本語と英語(English)
- このフォルダは本体(非公開)から `node _sync_web.js` で作り直しています。ここを直接直さないでください
- 提供: 介護と支援の相談どころ「そよぎ」 https://soudansoyogi.com/
